- `loadCommandCodeTaste`（L423-445）：只读扫描 `<home>/.commandcode/taste`，`commandCodePackageFiles` 只认 `taste.md` + 一级安全目录（L392-410）。✓

bridge.js 数据装配审计：

- `getTree({cwd})` 唯一外部输入是 `cwd` 字符串，仅喂给 `projectDirForCwd`（=`join(projectRootFor(cwd), ".dsh", "taste")`），随后一切读取都经 `listTasteFiles`/`readTasteFile` 白名单。**无 `file`/`dir`/`relPath`/`path` 形参直通**——即便恶意 `cwd`，也只能改读「哪个项目的 `.dsh/taste`」目录，且只能读出 `taste.md`（用户自己的偏好文件），无法逃出 taste 目录、无法读任意路径。✓

- `authority:"loopback"` → `trustedHosts=[]` → `isTrustedApiRequest`（L184-198）只放行 loopback 同源（Host 头 loopback + 非 cross-site + Origin 同源）；`dsh-web-app/cordis.patch.yml` 中 webserver `host: !!js ctx.webStartup.host ?? '127.0.0.1'`（默认 loopback）。✓

> 结论：白名单封闭、loopback 只读、解析后 JSON 无原始字节——**安全边界无破洞**。唯一轻微考量：返回里含 `dir` 绝对路径（含 home 目录路径），但 loopback-only 且为浏览器自身可得知的信息，非越权泄露（不判 blocker，列入轻微提示）。
